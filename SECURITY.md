# Security and privacy reports

Use [GitHub private vulnerability reporting](https://github.com/boriskra/astroattitude/security/advisories/new)
for vulnerabilities or suspected secret exposure. Do not post credentials, private
recordings or identifying observation metadata in public issues.

If private reporting is unavailable, open an issue requesting a private contact
channel without including sensitive details. Wait for that channel before sharing
those details. A synthetic reproducer is preferred.

This experimental project does not offer a response-time guarantee. Update to the
latest reviewed source revision; no supported release branches are established yet.
